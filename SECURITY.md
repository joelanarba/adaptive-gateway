# Security policy

This is an experimental project. No supported production release or completed
penetration test is claimed. Read [the audit](docs/PROJECT_AUDIT.md),
[security boundaries](docs/SECURITY.md) and [limitations](docs/LIMITATIONS.md)
before exposing a deployment.

Report suspected vulnerabilities privately using the repository's GitHub
“Report a vulnerability” feature if it is enabled. If it is unavailable, open a
minimal issue requesting a private reporting channel, without exploit details,
credentials or personal data. Do not post secrets in public issues. There is no
guaranteed response SLA.

Include affected revision, a local/mock reproduction, impact and suggested fix.
Use only systems you own or are authorized to test. No real customer data is
needed. Dependency findings remain deployment blockers until reviewed.
